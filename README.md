# 本地公众号 Markdown 排版器

这是一个本地可用的微信公众号 Markdown 排版 MVP。它支持：

- Markdown 编辑与实时预览
- 导入 `.md` 文件
- 主题色、字号、行距调整
- 自定义 CSS
- 复制带内联样式的富文本到微信公众号后台
- 导出完整 HTML
- 本地自动保存草稿

## 使用方式

推荐用本地服务打开，这样浏览器的富文本剪贴板权限更稳定：

```powershell
node server.js
```

然后访问：

```text
http://localhost:8787
```

也可以直接双击 `index.html` 打开。若复制按钮受浏览器权限影响，请使用上面的本地服务方式。

## 公众号粘贴建议

点击“复制富文本”后，打开微信公众号后台图文编辑器，在正文区域直接粘贴。复制时程序会把预览里的 CSS 转成行内 `style`，这是公众号后台最稳定的样式保留方式。
